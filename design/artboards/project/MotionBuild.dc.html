Flutter build
  • engine/ pure Dart: board geometry, rules per mode, house rules, Mayhem cards & events, bots (Hard/Expert in an isolate), seeded replays for tests.
  • Board: CustomPainter for frame, tiles, yards and pyramid, cached as a Picture per skin; pucks are widgets (44 px hit box, Semantics label each); 3D camera = Transform with a Matrix4 perspective entry.
  • Dice: six faces in a Transform-ed Stack (or pre-rendered sprite sheet per skin for low-end phones).
  • State: flutter_riverpod; routing go_router; saves in drift (SQLite) + local backups; flutter_local_notifications for the gift.
  • Ads/IAP: google_mobile_ads (banner, interstitial, rewarded, UMP), in_app_purchase for Remove ads.
  • Wi-Fi: bonsoir (mDNS _ludomela._tcp), dart:io WebSocket server on the host, mobile_scanner + qr_flutter for join-by-QR.
  • Audio: audioplayers with a small sound bank; haptics via HapticFeedback.
Wi-Fi rooms protocol
  • Host-authoritative: the host rolls every die with Random.secure() and validates every move; guests send intents only.
  • Join by nearby list, 4-digit code or QR (ludomela://join?h=IP&p=PORT&c=CODE); app versions must match.
  • Messages (JSON): hello, seat, rules, start, turn, roll, move, sticker, state (full snapshot + seq), bye.
  • Heartbeat 2 s · "reconnecting" after 6 s · a bot holds the seat after 15 s · seat freed after 30 s.
  • Host leaves: game pauses 60 s, then ends with no winner. No coins at stake in rooms.
  • iOS: NSLocalNetworkUsageDescription + NSBonjourServices; Android: multicast lock while browsing.
