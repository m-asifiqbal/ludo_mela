DESIGN SYSTEM

Build spec v3. Every value here is a token: Flutter reads them from one LmTokens ThemeExtension, and screens never hard-code a colour, size or curve. The reference phone is 390×844 pt; everything scales from it.

1 · Colour tokens

Gradients run top → bottom: hi (top), mid (55 %), lo (bottom). lip is the solid 3D edge below a button or card. Player colours are fixed by seat and never re-themed, so colour-blind patterns (star, ring, lane arrow) always back them up.

2 · Type scale

Lilita One for anything a player reads at a glance, always with the navy outline. Baloo 2 for sentences. Sizes are logical pt and scale with the system text size (0.85–1.3); titles shrink to fit, never wrap mid-word.

7 · Motion tokens

Fast, springy, and always skippable. With Reduce Motion on, positions jump and only a 120 ms fade remains; the pie timer becomes a shrinking number.

8 · Flutter hand-off

One ThemeExtension; widgets read context.lm. Board, pucks and dice draw with CustomPainter; the dice toss uses a Transform with a perspective matrix (no 3D engine needed).

@immutable
class LmTokens extends ThemeExtension<LmTokens> {
  final Color navyInk, sky, royal, deep, panelHi, panelLo, rim, well;
  final LmGloss green, gold, blue, red, navy, grey; // hi, mid, lo, lip
  final Map<Seat, LmSeat> seats;   // main, dark, light, side
  final double c;                  // board cell, from screen width
  final Duration tap, enter, modal, toss, hop, turn; // 120/460/420/820/170 ms, 15 s
  final Curve spring, easeOut;     // (.34,1.56,.64,1) · (.2,.8,.2,1)
  ...
}
extension LmX on BuildContext {
  LmTokens get lm => Theme.of(this).extension<LmTokens>()!;
}

9 · Animal avatars

Every player is a friendly animal from the mela — never a cartoon person. Each one blinks every few seconds and twitches its ears; the motion stops with Reduce Motion. Players can swap to their own photo in Profile.
